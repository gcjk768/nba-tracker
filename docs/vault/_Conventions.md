# Conventions

- Flat vault, ≤2 folder levels; `Home.md` is the MOC; link with `[[wikilinks]]`.
- Tags only for status: `#active`, `#archived`. Frontmatter: `tags`, `updated`.
- Update **Changelog** and **App Overview** on every code change; path-qualify file references.
- Move, don't delete (use `Archive/`). Rough notes go to `Inbox.md`.
- NAS only: never write "Synology"/"DSM"; it is a UGREEN NAS.
- Scheme/tactic labels always carry a source tag (`measured` / `inferred` / `reported`); never present inferred as fact.
